# rustsheng — Документация (Русский)

Полная документация по **rustsheng** — кроссплатформенной утилите командной строки
для чтения/записи EEPROM и прошивки радиостанций Quansheng UV-K5 (и совместимых)
через последовательный порт.

> ⚠️ **Используйте на свой страх и риск.** Запись некорректного образа EEPROM или
> прошивка могут нарушить настройки или необратимо вывести радиостанцию из строя.
> Прошивка **не проверялась на реальном оборудовании** — см. [Обзор](overview.md#project-status).
